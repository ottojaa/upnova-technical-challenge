# Upnova Technical Challenge

Simple Node.js repo for running one-off scripts.

## Usage

Run any script:
```bash
node scripts/example.js
```

Or with arguments:
```bash
node scripts/example.js arg1 arg2
```

Using npm script:
```bash
npm run script scripts/example.js
```

## Structure

- `scripts/` - Place your one-off scripts here
- Each script can be run independently with `node`
